# Roman Baron — Supply Chain & IT Consulting

Portfolio website for my independent consulting practice: supply chain operations,
IT project management, ERP/WMS implementations, EDI integration, data strategy
and crisis management across Europe.

Static site (HTML/CSS/JS, no build step) deployed to GitHub Pages via
`.github/workflows/static.yml` on every push to `main`.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
